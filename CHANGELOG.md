## [0.1.0] — 2026-10-23

Первая рабочая версия: консольный аналог диспетчера задач.

### Added

- `list` — таблица процессов с сортировкой (CPU, память, PID, имя, пользователь,
  время работы, чтение/запись диска), фильтрами по тексту и пользователю,
  ограничением `-n`, показом командных строк (`-c`) и сводкой по системе.
- `watch` — живой монитор: обновление в реальном времени, полоски загрузки CPU и
  памяти, спакрлайн истории CPU, прокрутка и выделение строк, панели «справка» и
  «подробности о процессе», горячие клавиши для сортировки, фильтра, снятия
  задач, паузы и интервала обновления.
- `info` — подробности о процессе: состояние, пользователь, родитель и цепочка
  процессов, число дочерних и всех процессов в ветке, CPU в процентах всех ядер
  и одного ядра, резидентная и виртуальная память, время работы и запуска,
  чтение/запись диска, исполняемый файл, рабочий каталог, командная строка.
- `tree` — дерево процессов с соединительными линиями, агрегатами по ветвям
  (суммарные CPU и память, число процессов), фильтром по подстрокам, выбором
  корня и ограничением глубины; защита от циклов и осиротевших ветвей.
- `kill` — завершение процессов по PID или имени (в том числе нескольких за
  раз), с подтверждением, режимом проверки `--dry-run`, мягким завершением
  `--terminate`, завершением дочерних процессов и итоговым отчётом о том, что
  реально завершилось.
- `summary` — сводка по производительности: модель и частота процессора, общая
  загрузка и загрузка по каждому ядру, память и подкачка, диски с процентами
  занятого места, сеть со скоростями приёма/передачи, список самых активных
  процессов.
- Вывод в JSON (`--json`) для всех команд, кроме живого монитора.
- Раскраска по уровню нагрузки с автоопределением терминала, отключение через
  `--no-color` или `NO_COLOR`; режим ASCII-рамок `--ascii`.
- Выравнивание таблиц по ширине терминала с обрезкой содержимого.
- Нормализация процентов CPU по числу ядер — как в диспетчере задач.
- Диагностика этапов работы через переменную `PROCMAN_TIMING=1`.

### Notes

- Первый снимок на Windows стоит ~1.3 с (разовый сбор счётчиков производительности
  ~0.63 с и прогрев счётчиков процессов), последующие обновления — ~20 мс.
  Подробности: [docs/INTERNALS.md](docs/INTERNALS.md).
- 29 юнит-тестов, сборка без предупреждений `clippy` (all + pedantic), код без `unsafe`.
